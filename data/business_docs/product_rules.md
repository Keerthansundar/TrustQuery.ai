# Product Rules

- "Product" means products.name. "Category" means products.category.
- Categories: Laptop, Phone, Tablet, Audio, Accessories.
- Phone: Nova X1, Nova Lite, Pixelon 9, Orbit S, Zenith Max.
- Laptop: UltraBook Pro 14, WorkStation 16, StudyBook 15, GameForce 17.
- "Best selling" by default means highest completed REVENUE; use units (SUM(quantity)) only if the user says units, volume or quantity.
- Break ties by product name ascending.
